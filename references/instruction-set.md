# FX5U 常用指令参考

## 基本触点指令

| 指令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| LD | 载入常开触点（母线开始） | `LD X0` | 常开触点开始一个逻辑行 |
| LDI | 载入常闭触点 | `LDI X0` | 常闭触点开始一个逻辑行 |
| AND | 串联常开触点 | `AND X1` | 与常开触点串联 |
| ANI | 串联常闭触点 | `ANI X1` | 与常闭触点串联 |
| OR | 并联常开触点 | `OR X2` | 或常开触点并联 |
| ORI | 并联常闭触点 | `ORI X2` | 或常闭触点并联 |
| ORB | 电路块并联 | `ORB` | 连接两个并联电路块（无操作数） |
| ANB | 电路块串联 | `ANB` | 连接两个串联电路块（无操作数） |

## 脉冲检测指令

| 指令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| LDP | 载入上升沿脉冲 | `LDP X0` | 上升沿（OFF→ON）导通一个扫描周期 |
| LDF | 载入下降沿脉冲 | `LDF X0` | 下降沿（ON→OFF）导通一个扫描周期 |
| ANDP | 串联上升沿脉冲 | `ANDP X1` | 与上升沿串联 |
| ANDF | 串联下降沿脉冲 | `ANDF X1` | 与下降沿串联 |
| ORP | 并联上升沿脉冲 | `ORP X2` | 或上升沿并联 |
| ORF | 并联下降沿脉冲 | `ORF X2` | 或下降沿并联 |

## 输出控制指令

| 指令 | 功能 | 示例 | 使用场景 |
|------|------|------|----------|
| OUT | 条件输出 | `OUT Y0` | 输入条件为 ON 时输出，为 OFF 时停止。不需要自锁时使用 |
| SET | 置位输出 | `SET Y0` | 置位后保持 ON，直到 RST 复位。需要自锁保持时使用 |
| RST | 复位输出 | `RST Y0` | 复位 SET 置位的软元件 |

**SET/RST 使用原则**：
- 启动/停止控制：LDP 启动 → SET M0，LD 停止 → RST M0
- 急停时必须 RST 所有输出和中间继电器
- SET/RST 配对使用，不建议混用 OUT 和 SET/RST 控制同一输出

**OUT 使用原则**：
- 互锁电路中的输出控制适合用 OUT（条件不成立自动断开）
- 定时器/计数器必须用 OUT 指令（扩展格式）
- 简单的条件输出（无需自锁）优先用 OUT

## 定时器指令

### 通用定时器（T0~T511，100ms 时基）

扩展格式（推荐）：
```
"8"  ""  "OUT"  "T0"   ""  ""  ""     ← 指令行
""   ""  ""     "K50"  ""  ""  ""     ← 参数行，K50 = 5.0秒
```

K 值计算：K = 秒数 × 10
- 0.5 秒 → K5
- 1.0 秒 → K10
- 3.0 秒 → K30
- 5.0 秒 → K50
- 10 秒 → K100
- 45 秒 → K450

定时器触点：定时器线圈得电后开始计时，计时到达后其常开触点 `LD Tx` 导通，常闭触点 `ANI Tx` 断开。

### 定时器复位

两种方式：
1. 输入条件断开 → 当前值清零（无自锁电路自然复位）
2. RST 指令 → 强制复位（用于循环控制中手动复位）

## 计数器指令

同定时器格式，扩展格式参数独立行：
```
"OUT"  "C0"     ← 指令行
""     "K10"    ← 参数行，计数 10 次
```

## 置位/复位指令

### SET（置位）
- `SET M0` — 使 M0 为 ON 并保持
- `SET Y0` — 使 Y0 为 ON 并保持
- `SET F0` — 设置报警器

### RST（复位）
- `RST M0` — 使 M0 为 OFF
- `RST Y0` — 使 Y0 为 OFF
- `RST T0` — 复位定时器（当前值清零，触点复位）
- `RST C0` — 复位计数器（当前值清零，触点复位）
- `RST F0` — 复位报警器

## 程序控制指令

| 指令 | 功能 | 说明 |
|------|------|------|
| MC | 主站控制开始 | 条件 ON 时执行 MC~MCR 之间的程序 |
| MCR | 主站控制解除 | 解除 MC 控制 |
| FEND | 主程序结束 | 主程序与子程序/中断程序的分界 |
| END | 顺控程序结束 | 必须作为程序最后一行 |
| STOP | 停止运算 | 停止顺控程序运算 |
| NOP | 空操作 | 无处理 |

## 特殊功能指令（常用）

| 指令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| PLS | 上升沿脉冲输出 | `PLS M0` | 输入 ON 时，M0 导通一个扫描周期 |
| PLF | 下降沿脉冲输出 | `PLF M0` | 输入 OFF 时，M0 导通一个扫描周期 |
| FF | 输出取反 | `FF Y0` | 软元件状态取反 |
| ALT | 交替输出 | `ALT Y0` | 每次执行取反一次 |
| ALTP | 脉冲交替输出 | `ALTP Y0` | 脉冲执行型取反 |

## 报警器指令

| 指令 | 功能 | 说明 |
|------|------|------|
| OUT F | 报警器输出 | 输出到报警器 |
| SET F | 报警器设置 | 报警器动作并保持 |
| RST F | 报警器复位 | 复位报警器 |
| ANS | 带判断时间的报警器设置 | 信号持续时间超过设定值才报警 |
| ANR | 报警器复位（小号码） | 复位编号最小的已动作报警器 |
| ANRP | 脉冲型报警器复位 | ANR 的脉冲执行型 |

## 互锁模式

### 正反转互锁（硬件 + 软件）

```
LD    M10       ← 正转指令
ANI   Y1        ← 互锁：反转电机未运行
ANI   X2        ← 正转限位
OUT   Y0        ← 正转输出

LD    M11       ← 反转指令
ANI   Y0        ← 互锁：正转电机未运行
ANI   X3        ← 反转限位
OUT   Y1        ← 反转输出
```

用 OUT 而不用 SET 的好处：条件不成立时自动断开，双重保护。

## 闪烁信号生成（1Hz）

```
LD    M0        ← 运行标志
ANI   T0        ← T0 未到
OUT   T1        ← 亮周期定时器
      K5            ← 0.5 秒

LD    T1        ← 亮周期到
OUT   T0        ← 灭周期定时器
      K5            ← 0.5 秒

LD    T1        ← T1 计时期间
SET   M2        ← 灯亮

LD    T0        ← T0 计时期间
RST   M2        ← 灯灭

LDP   T0        ← 灭周期结束
RST   T1        ← 复位 T1
RST   T0        ← 复位 T0（重新开始闪烁）
```
