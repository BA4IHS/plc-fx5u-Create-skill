# FX5U 常用指令参考

**优先级说明**：
- ★★★ 核心指令：几乎所有程序都会用到，必须掌握
- ★★ 常用指令：大部分程序会用到
- ★ 扩展指令：特定场景使用

## 合并指令 ★★

| 指令 | 功能 | 说明 |
|------|------|------|
| ANB | 梯形图块串联连接 | 连接两个串联电路块（无操作数） |
| ORB | 梯形图块并联连接 | 连接两个并联电路块（无操作数） |
| MPS | 存储运算结果（推入堆栈） | 分支起点，将当前结果压入堆栈 |
| MRD | 读取堆栈存储的运算结果 | 中间分支，读取堆栈中同层结果 |
| MPP | 读取并复位堆栈（弹出） | 分支终点，读出堆栈并弹出 |
| INV | 运算结果取反 | 将当前逻辑运算结果取反（无操作数） |
| MEP | 运算结果上升沿脉冲化 | 检测到上升沿时导通一个扫描周期（无操作数） |
| MEF | 运算结果下降沿脉冲化 | 检测到下降沿时导通一个扫描周期（无操作数） |

INV/MEP/MEF 使用示例：

```
LD    X0
INV               ← 将 X0 的运算结果取反
OUT   Y0          ← X0 OFF 时 Y0 为 ON

LD    X1
MEP               ← X1 上升沿时导通一个周期
SET   M0
```

## 输出控制指令 ★★★

| 指令 | 功能 | 示例 | 使用场景 |
|------|------|------|----------|
| OUT | 条件输出 | `OUT Y0` | 输入条件为 ON 时输出，为 OFF 时停止。不需要自锁时使用 |
| OUTH | 高速定时器输出 | `OUTH T0` | 1ms 时基高速定时器（T0~T255） |
| OUTHS | 高速保持定时器输出 | `OUTHS T0` | 1ms 时基高速累计定时器，保持当前值 |
| OUT ST | 低速累计定时器输出 | `OUT ST0` | 100ms 时基低速累计定时器 |
| OUTH ST | 累计定时器输出 | `OUTH ST0` | 100ms 时基累计定时器 |
| OUTHS ST | 高速累计定时器输出 | `OUTHS ST0` | 10ms 时基高速累计定时器 |
| OUT C | 计数器输出 | `OUT C0` | 16 位计数器（C0~C199）或 32 位（C200~C255） |
| OUT LC | 超长计数器输出 | `OUT LC0` | 32 位长计数器，保持型 |
| SET | 置位输出 | `SET Y0` | 置位后保持 ON，直到 RST 复位。需要自锁保持时使用 |
| RST | 复位输出 | `RST Y0` | 复位 SET 置位的软元件 |

**SET/RST 使用原则**：
- 启动/停止控制：LDP 启动 → SET M0，LD 停止 → RST M0
- 急停时必须 RST 所有输出和中间继电器
- SET/RST 配对使用，不建议混用 OUT 和 SET/RST 控制同一输出

**OUT 使用原则**：
- 互锁电路中的输出控制适合用 OUT（条件不成立自动断开）
- 定时器/计数器必须用 OUT 指令（扩展格式）
- 简单的条件输出（无需自锁）优先用 OUT

## 定时器指令 ★★★

### 定时器类型与时基

| 定时器范围 | 时基 | 计时范围 | 指令格式 |
|-----------|------|---------|---------|
| T0~T199 | 100ms | 0.1s~3276.7s | `OUT Tn` |
| T200~T255 | 10ms | 0.01s~327.67s | `OUT Tn` |
| T0~T255 | 1ms | 0.001s~32.767s | `OUTH Tn` |
| T0~T255 | 1ms 保持 | 0.001s~32.767s | `OUTHS Tn` |
| ST0~ST255 | 100ms 累计 | 0.1s~3276.7s | `OUT STn` |

累计定时器（OUTH/OUTHS/OUT ST 系列）：输入条件断开时保持当前值，再次接通后继续计时。普通定时器输入断开则清零。

### 扩展格式（2 行）

```
"8"  ""  "OUT"  "T0"   ""  ""  ""     ← 指令行
""   ""  ""     "K50"  ""  ""  ""     ← 参数行，K50 = 5.0秒（100ms时基）
```

**K 值计算**：K = 秒数 × 时基倒数
- 100ms 时基：K = 秒数 × 10（0.5s→K5, 1s→K10, 3s→K30, 5s→K50, 10s→K100, 45s→K450）
- 10ms 时基：K = 秒数 × 100
- 1ms 时基：K = 秒数 × 1000

定时器触点：定时器线圈得电后开始计时，计时到达后其常开触点 `LD Tx` 导通，常闭触点 `ANI Tx` 断开。

### 定时器复位

1. 输入条件断开 → 当前值清零（普通定时器，无自锁电路自然复位）
2. `RST Tn` 指令 → 强制复位（用于循环控制中手动复位）
3. 累计定时器即使输入断开也不清零，必须用 RST 复位

## 计数器指令 ★★★

### 计数器类型

| 计数器范围 | 类型 | 计数范围 | 指令格式 |
|-----------|------|---------|---------|
| C0~C199 | 16 位加计数 | 0~32767 | `OUT Cn` |
| C200~C255 | 32 位加减计数 | -2147483648~2147483647 | `OUT Cn` |
| LC0~LC255 | 32 位长计数 | -2147483648~2147483647（保持） | `OUT LCn` |

32 位计数器（C200~C255）的计数方向由特殊继电器 SM200~SM255 控制：
- SM200~SM255 ON → 减计数
- SM200~SM255 OFF → 加计数

> FX3U 中用 M8200~M8234 控制 C200~C234 方向，迁移到 FX5U 时需替换为 SM200~SM255。

### 扩展格式（2 行）

```
"20"  ""  "OUT"  "C0"     ← 指令行
""    ""  ""     "K10"    ← 参数行，计数 10 次
```

计数器触点：计数器当前值等于设定值时，其常开触点 `LD Cn` 导通，常闭触点 `ANI Cn` 断开。

### 计数器复位

- `RST Cn` → 强制复位（当前值清零，触点复位）
- `RST LCn` → 复位长计数器

## 置位/复位指令 ★★★

| 指令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| SET | 置位 | `SET M0` | 使软元件为 ON 并保持（报警器除外） |
| RST | 复位 | `RST M0` | 使软元件为 OFF（报警器除外） |
| SET F | 报警器置位 | `SET F0` | 报警器动作并保持 |
| RST F | 报警器复位 | `RST F0` | 复位报警器 |

支持的软元件：
- SET：M、Y、S、T、C、D（位）、F
- RST：M、Y、S、T、C、D（位）、F

**RST 复位范围**：
- `RST M0` — 使 M0 为 OFF
- `RST Y0` — 使 Y0 为 OFF
- `RST T0` — 复位定时器（当前值清零，触点复位）
- `RST C0` — 复位计数器（当前值清零，触点复位）
- `RST F0` — 复位报警器

## 程序控制指令 ★★

| 指令 | 功能 | 说明 |
|------|------|------|
| MC | 主站控制开始 | 条件 ON 时执行 MC~MCR 之间的程序 |
| MCR | 主站控制解除 | 解除 MC 控制 |
| CALL | 子程序调用 | 条件 ON 时调用标号 Pn 处的子程序 |
| CALLP | 脉冲型子程序调用 | 上升沿时执行一次子程序调用 |
| RET | 子程序返回 | 子程序结束，返回主程序 |
| SRET | 中断子程序返回 | 中断子程序结束，返回断点处 |
| IRET | 中断返回 | 中断服务程序结束，返回断点处 |
| FOR | 循环开始 | `FOR Kn` 循环执行 n 次 FOR~NEXT 之间的程序 |
| NEXT | 循环结束 | 循环结束，返回 FOR 处 |
| BREAK | 循环中断 | 强制跳出当前 FOR~NEXT 循环 |
| DI | 禁止中断 | 禁止所有可屏蔽中断 |
| EI | 允许中断 | 允许所有可屏蔽中断 |
| WDT | 看门狗刷新 | 刷新看门狗定时器，防止 CPU 停机 |
| FEND | 主程序结束 | 主程序与子程序/中断程序的分界 |
| END | 顺控程序结束 | 必须作为程序最后一行 |
| STOP | 停止运算 | 停止顺控程序运算 |
| NOP | 空操作 | 无处理，用于占位或删除指令 |

### MC/MCR CSV 格式

MC 指令占用 2 行：
```
"19"  ""  "MC"   "N0"    ""  ""  ""     ← 指令行: 嵌套层级 N0~N7
""    ""  ""     "M998"  ""  ""  ""     ← 参数行: 嵌套用 M
```
MCR 指令 1 行：`"N0"` 与 MC 对应。

### 子程序结构

```
[主程序]
LD    X0
CALL  P10          ← 调用子程序 P10
FEND               ← 主程序结束

[子程序 P10]
LD    X1
OUT   Y0
RET                ← 子程序返回

END                ← 程序结束
```

### FOR/NEXT 循环

```
LD    X0
FOR   K5           ← 循环 5 次
LD    X1
INC   D0
NEXT               ← 循环结束
```

## 报警器指令 ★★

| 指令 | 功能 | 说明 |
|------|------|------|
| OUT F | 报警器输出 | 输出到报警器 |
| SET F | 报警器设置 | 报警器动作并保持 |
| RST F | 报警器复位 | 复位报警器 |
| ANS | 带判断时间的报警器设置 | 信号持续时间超过设定值才报警，需 3 行格式 |
| ANR | 报警器复位（小号码） | 复位编号最小的已动作报警器 |
| ANRP | 脉冲型报警器复位 | ANR 的脉冲执行型 |

### ANS 指令 CSV 格式

ANS 指令占用 **3 行**：指令行 + 时间参数行 + 报警器号行。

```
"2"  ""  "ANS"  "T0"   ""  ""  ""     ← 指令行: 内部用定时器 T0~T199
""   ""  ""     "K20"  ""  ""  ""     ← 参数行: 判断时间(100ms单位, K20=2秒)
""   ""  ""     "F0"   ""  ""  ""     ← 参数行: 报警器号
```

格式说明：
- 第 1 行：步号 + ANS + **定时器号**（T0~T199，ANS 内部使用，不可与程序其他定时器冲突）
- 第 2 行：步号空 + 指令空 + **K 值**（判断时间，100ms 时基）
- 第 3 行：步号空 + 指令空 + **F 号**（报警器，如 F0）
- `ANS Tn Kn Fn` 表示信号持续 Kn×100ms 后置位 Fn

不符合的格式：
- `ANS Fn Kn`（紧凑格式）
- `ANS Fn` + 扩展行 Kn（少了一行，且顺序不对）
- 正确格式：`ANS Tn` + `Kn` + `Fn`（3 行扩展格式）

## 比较触点指令 ★★

比较触点用于数据比较，结果为真时触点导通。

### 16 位有符号比较（BIN 16 位）

| 指令 | 功能 | 示例 | 说明 |
|------|------|------|------|
| LD= | 载入等于比较 | `LD= D0` | D0 = K 时导通 |
| LD> | 载入大于比较 | `LD> D3` | D3 > K 时导通 |
| LD< | 载入小于比较 | `LD< D35` | D35 < 值 时导通 |
| LD<> | 载入不等于比较 | `LD<> D10` | D10 ≠ K 时导通 |
| LD<= | 载入小于等于 | `LD<= D20` | D20 ≤ K 时导通 |
| LD>= | 载入大于等于 | `LD>= D30` | D30 ≥ K 时导通 |
| AND= | 串联等于比较 | `AND= C0` | 串联，C0 = K 时导通 |
| AND> | 串联大于比较 | `AND> D110` | 串联，值 > K 时导通 |
| AND< | 串联小于比较 | `AND< D106` | 串联，值 < K 时导通 |
| AND<> | 串联不等于比较 | `AND<> D10` | 串联，D10 ≠ K 时导通 |
| AND<= | 串联小于等于 | `AND<= D20` | 串联，D20 ≤ K 时导通 |
| AND>= | 串联大于等于 | `AND>= D30` | 串联，D30 ≥ K 时导通 |
| OR= | 并联等于比较 | `OR= D2` | 并联，D2 = K 时导通 |
| OR> | 并联大于比较 | `OR> D5` | 并联，D5 > K 时导通 |
| OR< | 并联小于比较 | `OR< D8` | 并联，D8 < K 时导通 |
| OR<> | 并联不等于比较 | `OR<> D10` | 并联，D10 ≠ K 时导通 |
| OR<= | 并联小于等于 | `OR<= D20` | 并联，D20 ≤ K 时导通 |
| OR>= | 并联大于等于 | `OR>= D30` | 并联，D30 ≥ K 时导通 |

| 指令 | 功能 | 说明 |
|------|------|------|
| LDD= | 载入双字等于比较 | (D1,D0) = K 时导通 |
| LDD> | 载入双字大于比较 | (D1,D0) > K 时导通 |
| LDD< | 载入双字小于比较 | (D1,D0) < K 时导通 |

| LDD<= | 载入双字小于等于 | (D1,D0) ≤ K 时导通 |
| LDD>= | 载入双字大于等于 | (D1,D0) ≥ K 时导通 |
| ANDD= | 串联双字等于比较 | 串联，(D1,D0) = K 时导通 |
| ANDD> | 串联双字大于比较 | 串联，(D1,D0) > K 时导通 |

| ORD< | 并联双字小于比较 | 并联，(D1,D0) < K 时导通 |

### 无符号比较

在指令后加 `_U` 后缀表示无符号比较：
- `LD=_U D0`：D0 与 K 无符号等于比较
- `LDD>_U D0`：(D1,D0) 与 K 无符号大于比较
- 所有比较触点指令均支持 `_U` 无符号版本

### 比较输出指令

| 指令 | 功能 | 说明 |
|------|------|------|
| CMP/CMPP | 16 位比较输出 | S1 vs S2，输出大/等/小于结果到 D/D+1/D+2 |
| CMP_U/CMPP_U | 16 位无符号比较输出 | 同上，无符号版本 |
| DCMP/DCMPP | 32 位比较输出 | (S1+1,S1) vs (S2+1,S2)，输出结果 |
| ZCP/ZCPP | 16 位带宽比较 | S vs S1~S2，输出区域结果到 D/D+1/D+2 |
| ZCP_U/ZCPP_U | 16 位无符号带宽比较 | 同上，无符号版本 |
| DZCP/DZCPP | 32 位带宽比较 | 32 位带宽比较输出 |

### CSV 格式（2 行，比较触点）

```
"37"  ""  "LD="  "D10"  ""  ""  ""      ← 指令行: 比较对象
""    ""  ""     "K4"   ""  ""  ""      ← 参数行: 比较值
```

### CSV 格式（3 行，比较输出 CMP）

```

```

## 堆栈指令 ★★

用于梯形图分层分支控制。

| 指令 | 功能 | 说明 |
|------|------|------|
| MPS | 存储当前运算结果 | 分支起点，将当前结果压入堆栈 |
| MRD | 读出堆栈 | 中间分支，读取堆栈中同层结果 |
| MPP | 读出并复位 | 分支终点，读出堆栈并弹出 |

三指令配合实现多层嵌套分支选择，均无操作数。

使用示例：

```
LD    X0
```

| D101 | 过程值 PV | -32768~32767 | 传感器反馈值 |
| D102 | 输出值 MV | 0~32767 | PID 控制输出（0~100% 对应 0~32767） |

| D105 | 微分时间 Td | 0~32767 | 微分作用时间（单位：100ms，0=无微分） |
| D106 | 采样周期 Ts | 1~32767 | PID 运算周期（单位：10ms，必须 > 扫描周期） |

使用注意事项：
1. 采样周期 Ts 必须大于程序扫描周期
2. 积分时间 Ti=0 时，积分作用无效
3. 微分时间 Td=0 时，微分作用无效
4. 输出值 MV 可通过特殊寄存器 SD414 读取
5. 支持自整定（极限循环法/阶跃响应法）

参数调整原则：
- P 参数：从小到大调整，直到系统开始振荡
- I 参数：在 P 参数基础上调整，消除稳态误差
- D 参数：抑制振荡，提高系统稳定性
- 调整顺序：先 P，再 I，最后 D

## 互锁模式 ★★★

### 正反转互锁（硬件 + 软件）

```
LD    M10       ← 正转指令
ANI   Y1        ← 互锁：反转电机未运行
ANI   X2        ← 正转限位
OUT   Y0        ← 正转输出

LD    M11       ← 反转指令
ANI   Y0        ← 互锁：正转电机未运行
ANI   X3        ← 反转限位
OUT   Y1        ← 反转输出
```

用 OUT 而不用 SET 的好处：条件不成立时自动断开，双重保护。

### 单按钮启停控制

```
LDP   X0        ← 按钮按下（上升沿）
ALT   M0        ← M0 状态取反

LD    M0        ← M0 为 ON 时
OUT   Y0        ← 输出启动
```

### 延时接通电路

```
LD    X0        ← 启动信号
OUT   T0        ← 定时器开始计时
      K100      ← 10 秒延时（100ms 时基）

LD    T0        ← 延时到
OUT   Y0        ← 输出接通
```

### 延时断开电路

```
LD    X0        ← 启动信号
OR    M0        ← 自锁
ANI   T0        ← 定时器未到
OUT   M0        ← 中间继电器

LD    M0        ← M0 为 ON 时
OUT   Y0        ← 输出接通

LDI   X0        ← 启动信号断开
AND   M0        ← M0 仍为 ON
OUT   T0        ← 定时器开始计时
      K50       ← 5 秒延时
```

## 闪烁信号生成（1Hz） ★★

### 方法 1：SM412 系统时钟（最简）

```
LD    M0        ← 运行标志
AND   SM412     ← 1 秒时钟（0.5s ON / 0.5s OFF）
OUT   Y0        ← 灯以 1Hz 闪烁
```

### 方法 2：双定时器交替

```
LD    M0        ← 运行标志
ANI   T0        ← T0 未到
OUT   T1        ← 亮周期定时器
      K5            ← 0.5 秒

LD    T1        ← 亮周期到
OUT   T0        ← 灭周期定时器
      K5            ← 0.5 秒

LD    T1        ← T1 计时期间
SET   M2        ← 灯亮

LD    T0        ← T0 计时期间
RST   M2        ← 灯灭

LDP   T0        ← 灭周期结束
RST   T1        ← 复位 T1
RST   T0        ← 复位 T0（重新开始闪烁）
```

## 附录 C：GX Works2 → GX Works3 关键指令差异

### TO / FROM 参数顺序

| GX Works2 (FX3U) | GX Works3 (FX5U) |
|------------------|------------------|
| `TO n1 n2 S n3`（模块号→BFM号→源→字数） | `TO UnHn S1 S2 n`（单元号:BFM号→源→字数，参数合并） |

FX5U 的 CSV 中使用 4 行扩展格式，参数顺序见本文 FROM/TO 章节。

### INC / DEC 数据类型

FX3U 的 INC/DEC 仅支持 16 位有符号（-32768~32767）。FX5U 新增：
- `INC_U` / `DEC_U`：16 位无符号（0~65535）
- `DINC` / `DDEC`：32 位（-2147483648~2147483647）
- `DINC_U` / `DDEC_U`：32 位无符号

当处理值可能超过 32767 时，必须使用 INC_U 或 DINC。

### 四则运算运算符

FX5U 中 ADD/SUB/MUL/DIV 可直接用 `+` `-` `*` `/` 运算符输入：
```
LD   X0
[+   D0  D1  D2]    ← D0 + D1 → D2
```
CSV 中仍使用 ADD/ADDP/DADD 等指令名。

### 计数器方向控制

| FX3U | FX5U |
|------|------|
| M8200 控制 C200 方向 | SM200 控制 C200 方向 |
| M8201→C201 ... M8234→C234 | SM201→C201 ... SM255→C255 |
| ON=减计数，OFF=加计数 | 相同逻辑 |
