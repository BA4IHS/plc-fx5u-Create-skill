# PLC 程序示例

## 示例 1：电机间歇循环控制

**需求**：按下启动按钮 X0，电机 Y0 运行 5 秒 → 停止 3 秒 → 循环。按下急停 X1，立即停止所有。

**软元件分配**：
- 启动按钮：X0
- 急停按钮：X1
- 电机：Y0
- 运行标志：M0
- 定时器 T0：5 秒 (K50)
- 定时器 T1：3 秒 (K30)

**程序**（扩展格式，注解列全部留空）：

```
Step  | Instr | Device
0     | LDP   | X0
2     | SET   | M0
4     | LD    | X1
6     | RST   | M0
8     | RST   | Y0
10    | RST   | T0
12    | RST   | T1
14    | LD    | M0
16    | ANI   | T1
18    | OUT   | T0
      |       | K50         ← 参数行（步号为空）
20    | LD    | T0
22    | OUT   | T1
      |       | K30         ← 参数行（步号为空）
24    | LDP   | T1
26    | RST   | T0
28    | RST   | T1
30    | LD    | M0
32    | ANI   | T0
34    | SET   | Y0
36    | LD    | T0
38    | RST   | Y0
40    | END   |
```

> **重要**：CSV 第 7 列（注解）必须全部为空 `""`。填入任何文本都会导致 GX Works3 导入失败。

## 示例 2：故障报警指示灯

**需求**：故障信号 X0 出现时，报警灯 Y0 以 1Hz 闪烁。按下复位 X1，若故障仍在则灯常亮；故障消失则灯灭。

**软元件分配**：
- 故障信号：X0
- 复位按钮：X1
- 报警灯：Y0
- 故障标志：M0
- 已复位标志：M1
- 闪烁信号：M2
- T0：灭 0.5 秒 (K5)、T1：亮 0.5 秒 (K5)

**核心逻辑**：
1. X0 上升沿 → SET M0, RST M1（开始闪烁）
2. X0 下降沿 → RST M0, RST M1（故障消失，全复位）
3. 闪烁生成（M0=1, M1=0 时）：T1 和 T0 交替产生 0.5 秒脉冲
4. 闪烁输出：M2=1 → SET Y0，M2=0 → RST Y0
5. 复位处理：X1 上升沿 且 M0=1 → SET M1（转常亮）
6. 常亮状态：M0=1, M1=1, X0=1 → SET Y0
7. 故障消失且已复位：M0=1, M1=1, X0=0 → RST 所有
8. 无故障时 ANI M0 → RST Y0

## 示例 3：送料小车自动循环

**需求**：按送料按钮 X0，小车前进(Y0)到卸料处 B(X2) → 卸料 30s → 后退(Y1)到装料处 A(X1) → 装料 45s → 循环。

**软元件分配**：
- 送料按钮：X0
- 后限位 SQ1(装料处)：X1
- 前限位 SQ2(卸料处)：X2
- 电机正转(前进)：Y0
- 电机反转(后退)：Y1
- 循环使能：M0
- 前进指令：M10
- 后退指令：M11
- T0：卸料 30s (K300)
- T1：装料 45s (K450)

**核心逻辑**：
1. LDP X0 → SET M0, SET M10（启动 + 前进）
2. M10 ON 且未到 X2 → OUT Y0（前进），ANI Y1 互锁
3. M10 ON 且 X2 ON → RST M10，启动 T0 卸料
4. T0 到时 → SET M11（后退）
5. M11 ON 且未到 X1 → OUT Y1（后退），ANI Y0 互锁
6. M11 ON 且 X1 ON → 启动 T1 装料，RST M11
7. T1 到时 → SET M10, RST M11（循环回到前进）

## 示例 4：电机点动与长运行互锁

**需求**：长运行按钮 X0/长停止 X1（自锁），点动按钮 X3（按住运行松手停），点动优先。

**软元件分配**：
- 长启动：X0
- 长停止：X1
- 点动：X3
- 电机：Y0
- 长运行标志：M10

**核心逻辑**：
1. LDP X0 → SET M10（长运行）
2. LD X1 → RST M10（长停止）
3. LDP X3 → RST M10（点动互锁，停止长运行）
4. M10 ON → SET Y0（长运行输出）
5. X3 ON → SET Y0（点动输出）
6. M10 OFF 且 X3 OFF → RST Y0（两者都停时复位）

## 示例 5：两人抢答器

**需求**：主持人按 X0 复位，按 X3 开始倒计时，A(X1)/B(X2) 先按者亮灯并封锁对方，超时违规灯亮；A/B 得分确认。

**核心设计**：等待状态 M0、A/B 抢答标志、封锁标志 M3、违规标志 M10、定时器 T0 限时、计数器 C0/C1 计分。

## 示例 6：多速电机控制（数据传送 + 比较）

**需求**：X0 启动，X1/X2 选择低速/高速，Y0 低速输出，Y1 高速输出，Y2 运行指示灯。高速时 Y0 不能输出（互锁）。

**软元件分配**：
- 启动按钮：X0
- 低速选择：X1
- 高速选择：X2
- 低速输出：Y0
- 高速输出：Y1
- 运行指示灯：Y2
- 运行标志：M0

**核心逻辑**：
1. LDP X0 → SET M0（启动）
2. LD X1 → RST M0（停止）
3. LD M0 → ANI Y1 → AND X1 → OUT Y0（低速，高速互锁）
4. LD M0 → ANI Y0 → AND X2 → OUT Y1（高速，低速互锁）
5. LD M0 → OUT Y2（运行指示灯）

## 示例 7：定时切换双泵（定时器 + 计数器 + 互锁）

**需求**：X0 启动，泵 A（Y0）运行 60 分钟 → 泵 B（Y1）运行 60 分钟 → 循环。X1 急停复位全部。X2 手动切换泵。

**软元件分配**：
- 启动：X0
- 急停：X1
- 手动切换：X2
- 泵 A：Y0
- 泵 B：Y1
- 运行标志：M0
- 泵选择标志：M1（0=A，1=B）
- T0：60 分钟 (K36000)

**核心逻辑**：
1. LDP X0 → SET M0（启动）
2. LD X1 → RST M0, RST M1, RST Y0, RST Y1, RST T0（急停）
3. LDP X2 → FF M1（手动切换泵）
4. LD M0 → ANI M1 → ANI T0 → OUT Y0（泵 A 运行）
5. LD M0 → AND M1 → ANI T0 → OUT Y1（泵 B 运行）
6. LD M0 → OUT T0 (K36000)（60 分钟定时）
7. LDP T0 → FF M1, RST T0（定时到切换泵，复位定时器）

## 示例 8：顺序启动三台电机（定时器级联 + 互锁）

**需求**：X0 启动后，电机 M1(Y0) 先运行 → 5 秒后 M2(Y1) 启动 → 再 5 秒后 M3(Y2) 启动。停止时全部立即停止。X1 急停。

**软元件分配**：
- 启动：X0
- 急停：X1
- 电机 M1：Y0
- 电机 M2：Y1
- 电机 M3：Y2
- 运行标志：M0
- T0：5 秒延时（K50）
- T1：10 秒延时（K100）

**核心逻辑**：
1. LDP X0 → SET M0（启动）
2. LD X1 → RST M0, RST Y0, RST Y1, RST Y2, RST T0, RST T1（急停）
3. LD M0 → OUT Y0（M1 立即启动）
4. LD M0 → OUT T0 (K50)（5 秒延时）
5. LD T0 → OUT Y1（M2 启动）
6. LD M0 → OUT T1 (K100)（10 秒延时）
7. LD T1 → OUT Y2（M3 启动）

## 示例 9：按钮控制八路抢答器（互锁 + SET/RST）

**需求**：X0 主持人复位，X1~X4 四路抢答。先按者 Y1~Y4 对应灯亮并封锁其余。超时 10 秒未按则全部灯闪。

**软元件分配**：
- 主持人复位：X0
- 抢答按钮 A~D：X1~X4
- 抢答灯 A~D：Y1~Y4
- 超时报警灯：Y5
- 等待标志：M0
- 封锁标志：M10
- T0：10 秒超时 (K100)
- SM412：1 秒时钟（闪烁用）

**核心逻辑**：
1. LDP X0 → SET M0, RST M10, RST Y1~Y5, RST T0（复位）
2. LD M0 → OUT T0 (K100)（开始计时）
3. LDP X1 → ANI M10 → SET Y1, SET M10, RST M0, RST T0（A 抢答，封锁）
4. LDP X2 → ANI M10 → SET Y2, SET M10, RST M0, RST T0（B 抢答）
5. LDP X3 → ANI M10 → SET Y3, SET M10, RST M0, RST T0（C 抢答）
6. LDP X4 → ANI M10 → SET Y4, SET M10, RST M0, RST T0（D 抢答）
7. LD T0 → ANI M10 → AND SM412 → OUT Y5（超时闪烁）

## 示例 10：步进顺序控制（STL 步进梯形图）

**需求**：X0 启动，S10 → S11 → S12 三步顺序执行。S10: Y0 亮 3 秒 → S11: Y1 亮 2 秒 → S12: Y2 亮 1 秒 → 回到 S10 循环。X1 停止。

**软元件分配**：
- 启动：X0
- 停止：X1
- 输出：Y0, Y1, Y2
- S10~S12：步进点
- T0：3 秒, T1：2 秒, T2：1 秒

**核心逻辑**：
1. LDP X0 → SET S10（启动第一步）
2. LD X1 → ZRST S0 S20（停止，批量复位步进点）
3. STL S10 → OUT Y0 → OUT T0 (K30) → LDP T0 → SET S11（步进）
4. STL S11 → OUT Y1 → OUT T1 (K20) → LDP T1 → SET S12（步进）
5. STL S12 → OUT Y2 → OUT T2 (K10) → LDP T2 → SET S10（循环）
6. RETSTL → END

## 示例 11：模拟量温度报警（FROM + 比较）

**需求**：从 0 号模块 BFM#29 读取温度值到 D10，温度 ≥ 80℃ 时 Y0 报警灯亮，温度 ≥ 100℃ 时 Y1 蜂鸣器响并 Y0 闪烁，X0 复位。

**软元件分配**：
- 复位按钮：X0
- 高温报警灯：Y0
- 高温蜂鸣器：Y1
- 温度值：D10
- 报警标志：M0
- SM412：1 秒时钟（闪烁用）

**核心逻辑**：
1. LD SM400 → FROM K0 K29 D10 K1（每扫描周期读温度）
2. LD>= D10 K80 → OR M0 → OUT M0（≥80℃ 报警锁存）
3. LD>= D10 K100 → OUT Y1（≥100℃ 蜂鸣器常亮）
4. LD M0 → ANI Y1 → OUT Y0（<100℃ 报警灯常亮）
5. LD M0 → AND Y1 → AND SM412 → OUT Y0（≥100℃ 报警灯闪烁）
6. LD X0 → RST M0, RST Y0, RST Y1（复位）

## 示例 12：MODBUS RTU 通信读写（ADPRW）

**需求**：X0 触发从站号 10 读取保持寄存器（功能码 03），起始地址 0，读 2 个字到 D100。X1 触发写入保持寄存器（功能码 06），地址 0，写 D200 的值。通信状态 M100 指示。

**软元件分配**：
- 读触发：X0
- 写触发：X1
- 读取数据：D100, D101
- 写入数据：D200
- 通信状态：M100

**核心逻辑**：
1. LDP X0 → ADPRW（6 行）：站号 K10 → 功能码 K3 → 起始地址 K0 → 读数量 K2 → 数据寄存器 D100 → 状态 M100
2. LDP X1 → ADPRW（6 行）：站号 K10 → 功能码 K6 → 起始地址 K0 → 写数量 K1 → 数据寄存器 D200 → 状态 M100

## 通用程序结构模板

```
[系统初始化/急停复位段]
  - SM402（初始脉冲）或急停信号触发 RST 所有输出和标志
  - ZRST 批量复位区间

[启动逻辑段]
  - LDP 启动按钮
  - SET 运行标志

[运行逻辑段]
  - LD 运行标志 + 互锁条件
  - 定时器/计数器级联
  - 比较指令分支

[停止/保护逻辑段]
  - 停止按钮 → RST
  - 限位保护
  - 互锁 ANI 对方输出

[输出控制段]
  - 条件组合 → SET/OUT 输出
  - 闪烁/报警输出

[通信/数据处理段]
  - FROM/TO 模块读写
  - ADPRW MODBUS 通信
  - 数据传送 MOV / 比较 CMP

[程序结束]
  - END
```

## 通用编程模式速查

| 模式 | 实现方式 | 适用场景 |
|------|---------|---------|
| 自锁保持 | LDP 启动 → SET M0，LD 停止 → RST M0 | 启停控制 |
| 互锁 | ANI Y1 串联到 Y0 控制回路 | 正反转/双泵 |
| 延时接通 | OUT T0 (Kn) → LD T0 → OUT Y0 | 延时启动 |
| 延时断开 | 自锁 + ANI T0 → OUT M0 → LD M0 → OUT Y0 | 延时停止 |
| 闪烁 | AND SM412 + OUT Y0 | 1Hz 报警闪烁 |
| 交替输出 | LDP X0 → ALT M0 | 单按钮启停 |
| 脉冲捕获 | PLS M0 / PLF M0 | 边沿触发 |
| 循环复位 | LDP T1 → RST T0, RST T1 | 定时循环 |
| 步进控制 | SET Sn + STL Sn | 顺序流程 |
| 批量复位 | ZRST M0 M999 | 急停全复位 |
