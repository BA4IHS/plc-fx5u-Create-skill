# PLC 程序测试用例

用于在 GX Works3 中验证生成的 CSV 是否正确，每条测试目标覆盖不同的指令。

---

## 1. 计数器 — OUT C / RST C

> 生成 FX5U PLC 程序：X0 是计数输入信号，X1 是复位按钮。要求对 X0 的上升沿计数 10 次后 Y0 输出 ON，按 X1 复位计数器。用扩展格式。

**测试指令**：OUT C / RST C / LDP

---

## 2. 脉冲输出 — PLS / PLF

> 生成 FX5U PLC 程序：X0 接通瞬间 Y0 输出一个扫描周期的脉冲（PLS），X1 断开瞬间 Y1 输出一个扫描周期的脉冲（PLF）。用扩展格式。

**测试指令**：PLS / PLF

---

## 3. 交替输出 — ALT / ALTP

> 生成 FX5U PLC 程序：X0 每按一次，Y0 状态取反一次（按一下ON，再按一下OFF，如此交替）。使用 ALTP 指令实现。用扩展格式。

**测试指令**：ALTP

---

## 4. 边沿触点 — ANDP / ANDF / ORP / ORF

> 生成 FX5U PLC 程序：X0 常开触点串联 X1 的上升沿检测（ANDP），满足条件时 SET Y0。X2 常开触点并联 X3 的下降沿检测（ORF），满足条件时 RST Y0。用扩展格式。

**测试指令**：ANDP / ANDF / ORP / ORF

---

## 5. 置位/复位优先互锁

> 生成 FX5U PLC 程序：X0 是正转启动，X1 是反转启动，X2 是停止。Y0 正转输出，Y1 反转输出。要求：
> 1. 正转和反转互锁，不能同时接通
> 2. 停止按钮复位所有
> 3. 正转运行时按反转按钮，先停正转再启动反转（反之亦然）
> 4. 使用 SET/RST 实现
> 用扩展格式。

**测试指令**：复杂互锁逻辑 / SET / RST

---

## 6. 定时器 + 计数器组合（有限循环）

> 生成 FX5U PLC 程序：按下 X0 启动，Y0 运行 3 秒 → 停止 2 秒 → 循环。循环满 5 次后自动停止，Y1 亮表示完成。X1 急停复位全部。用扩展格式。

**测试指令**：OUT T + OUT C 组合 / 多个定时器

---

## 7. 主控指令 — MC / MCR

> 生成 FX5U PLC 程序：X0 是主控开关。当 X0 接通时，MC~MCR 之间的程序正常执行（M0=ON 时 Y0=ON，M1=ON 时 Y1=ON）。当 X0 断开时，MC~MCR 之间的所有输出强制 OFF。嵌套层级 N1。用扩展格式。

**测试指令**：MC / MCR

---

## 8. 报警器指令 — ANS / ANR

> 生成 FX5U PLC 程序：X0 是故障信号。故障信号持续 2 秒以上才触发报警 F0，报警灯 Y0 亮。故障消失后按 X1（ANR 指令）复位报警器。用扩展格式。

**测试指令**：ANS / ANR / SET F / RST F

---

## 9. 比较输出 — 多条件状态机

> 生成 FX5U PLC 程序：X0、X1、X2 是三个选择开关。要求：
> - 仅 X0 接通 → Y0 亮
> - 仅 X1 接通 → Y1 亮
> - 仅 X2 接通 → Y2 亮
> - X0 和 X1 同时接通 → Y0 和 Y1 同时亮
> - 任意两个以上接通 → Y3 报警亮
> - X3 急停全部灭
> 使用 LD/AND/ANI/OR 组合实现。用扩展格式。

**测试指令**：复杂组合逻辑 / 多输出 / 优先级判断

---

## 10. 闪烁 + 移位 — SFT / SFL / SFR

> 生成 FX5U PLC 程序：按下 X0 启动，8 个 LED（Y0~Y7）依次循环点亮（跑马灯效果），每 0.5 秒移动一位。按下 X1 停止并全部复位。用定时器 + 自增逻辑实现移位效果。用扩展格式。

**测试指令**：定时器 + 移位逻辑 / 多位输出

---

## 测试注意事项

1. 每条用例生成后导入 GX Works3 验证
2. 检查是否有"无法读取软元件"、"梯形图配置不正确"等错误
3. 确认注解列全部为空
4. 确认定时器参数为扩展格式（参数独立行，步号为空）
5. 如发现格式或逻辑问题，记录错误行号和内容，反馈给 skill
