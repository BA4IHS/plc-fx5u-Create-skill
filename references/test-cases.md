# PLC 程序测试用例

用于在 GX Works3 中验证生成的 CSV 是否正确，每条测试目标覆盖不同的指令。

---

## 1. 计数器 — OUT C / RST C

> 生成 FX5U PLC 程序：X0 是计数输入信号，X1 是复位按钮。要求对 X0 的上升沿计数 10 次后 Y0 输出 ON，按 X1 复位计数器。用扩展格式。

**测试指令**：OUT C / RST C / LDP

---

## 2. 脉冲输出 — PLS / PLF

> 生成 FX5U PLC 程序：X0 上升沿 PLS M0 脉冲 → SET Y0 锁存（灯亮保持），X1 下降沿 PLF M1 脉冲 → RST Y0（灯灭）。用 M 继电器捕获脉冲后用 SET/RST 锁存，使脉冲效果可见。用扩展格式。

**测试指令**：PLS / PLF

---

## 3. 交替输出 — ALT / ALTP

> 生成 FX5U PLC 程序：X0 每按一次，Y0 状态取反一次（按一下ON，再按一下OFF，如此交替）。使用 ALTP 指令实现。用扩展格式。

**测试指令**：ALTP

---

## 4. 下降沿触点 — ORF

> 生成 FX5U PLC 程序：X0 为基极常开触点（测试时保持 OFF），ORF X1 并联下降沿检测。X1 从 ON 变为 OFF 时 ORF 导通一个扫描周期 → SET Y0 锁存。X0 按下 → RST Y0 复位。用扩展格式。

**测试指令**：ORF（并联下降沿触点）

---

## 5. 置位/复位优先互锁

> 生成 FX5U PLC 程序：X0 是正转启动，X1 是反转启动，X2 是停止。Y0 正转输出，Y1 反转输出。要求：
> 1. 正转和反转互锁，不能同时接通
> 2. 停止按钮复位所有
> 3. 正转运行时按反转按钮，先停正转再启动反转（反之亦然）
> 4. 使用 SET/RST 实现
> 用扩展格式。

**测试指令**：复杂互锁逻辑 / SET / RST

---

## 6. 定时器 + 计数器组合（有限循环）

> 生成 FX5U PLC 程序：按下 X0 启动，Y0 运行 3 秒 → 停止 2 秒 → 循环。循环满 5 次后自动停止，Y1 亮表示完成。X1 急停复位全部。用扩展格式。

**测试指令**：OUT T + OUT C 组合 / 多个定时器

---

## 7. 主控指令 — MC / MCR

> 生成 FX5U PLC 程序：X0 是主控开关。当 X0 接通时，MC~MCR 之间的程序正常执行（M0=ON 时 Y0=ON，M1=ON 时 Y1=ON）。当 X0 断开时，MC~MCR 之间的所有输出强制 OFF。嵌套层级 N1。用扩展格式。

**测试指令**：MC / MCR

---

## 8. 报警器指令 — ANS / ANR

> 生成 FX5U PLC 程序：X0 是故障信号。故障信号持续 2 秒以上触发报警 F0，报警灯 Y0 亮。按 X1（ANR 指令）复位报警器。**注意**：ANS 指令需 3 行扩展格式（ANS Tn / Kn / Fn），定时器号不可与其他定时器冲突。用扩展格式。

**测试指令**：ANS（3行扩展格式）/ ANR

---

## 9. 比较输出 — 多条件组合逻辑

> 生成 FX5U PLC 程序：X0、X1、X2 是三个选择开关。X3 急停全灭。要求：
> - 仅 X0 接通 → Y0 亮（X1/X2 的 ANI 互锁保证互斥）
> - 仅 X1 接通 → Y1 亮
> - 仅 X2 接通 → Y2 亮
> - X0+X1 同时接通 → Y0+Y1 亮（有并联回路），Y3 报警
> - X0+X2 或 X1+X2 同时接通 → 仅 Y3 报警（ANI 互锁阻断独立输出）
> - 任意 ≥2 个接通 → Y3 报警亮
> 使用 LD/AND/ANI/ORB 组合实现。用扩展格式。

**测试指令**：复杂组合逻辑 / ORB 电路块并联 / ANI 互锁

---

## 10. 跑马灯 — 计数器 + 比较指令

> 生成 FX5U PLC 程序：X0 启动，8 个 LED（Y0~Y7）依次循环点亮（跑马灯效果），每 0.5 秒移动一位。用 T0 定时器产生 0.5s 脉冲 → C0 计数器 0~7 循环 → AND= 比较指令根据 C0 值分别点亮 Y0~Y7。X1 停止并全部复位。用扩展格式。

**测试指令**：AND= 比较指令 / 计数器循环 / 多位输出

---

## 11. 数据传送 — MOV / DMOV

> 生成 FX5U PLC 程序：X0 按下时将常数 K100 传送到 D0，X1 按下时将 D0 的值复制到 D10。X2 按下时将 D0 和 D1 清零（ZRST D0 D11）。用扩展格式。

**测试指令**：MOV（2行格式）/ ZRST（2行格式）

---

## 12. 比较触点 — LD= / LD> / LD<

> 生成 FX5U PLC 程序：D0 存储当前计数值（用 C0 计数 X0 上升沿）。当 D0=5 时 Y0 亮，D0>5 时 Y1 亮，D0<5 时 Y2 亮。X1 复位 C0 和 D0。用扩展格式。

**测试指令**：LD= / LD> / LD<（比较触点 2 行格式）

---

## 13. 算术运算 — ADD / SUB

> 生成 FX5U PLC 程序：X0 按下时 D0+1→D0（INC），X1 按下时 D0-1→D0（DEC），X2 按下时 D0+K10→D10（ADD）。当 D10≥K20 时 Y0 亮。X3 复位全部。用扩展格式。

**测试指令**：INC / DEC（1行）/ ADD（3行格式）/ LD>=（比较触点）

---

## 14. 块传送 — BMOV

> 生成 FX5U PLC 程序：X0 按下时将 D0~D4 的 5 个字批量传送到 D10~D14（BMOV）。X1 按下时将 D0~D4 清零。用扩展格式。

**测试指令**：BMOV（3行格式）/ ZRST

---

## 15. 子程序 — CALL / RET / FEND

> 生成 FX5U PLC 程序：X0 常 ON 时调用子程序 P10（CALL P10）。子程序 P10 内：X1 ON 时 Y0 ON，X2 ON 时 Y1 ON。主程序以 FEND 结束，子程序以 RET 结束，程序最后 END。用扩展格式。

**测试指令**：CALL / FEND / RET / END

---

## 16. 循环 — FOR / NEXT

> 生成 FX5U PLC 程序：X0 按下时执行 FOR K3 循环 3 次，循环体内 D0 加 1（INC D0）。循环结束后 Y0 亮。X1 复位 D0 和 Y0。用扩展格式。

**测试指令**：FOR / NEXT / INC

---

## 17. 双定时器闪烁 — 自定义频率

> 生成 FX5U PLC 程序：M0 运行标志 ON 时，Y0 以 2 秒亮 / 1 秒灭的频率闪烁（非对称）。用两个定时器 T0（1秒 K10）和 T1（2秒 K20）实现。X0 启动 SET M0，X1 停止 RST M0。用扩展格式。

**测试指令**：OUT T（扩展格式）/ 双定时器交替 / SET/RST

---

## 18. 三行运算 — ADDP 带脉冲

> 生成 FX5U PLC 程序：X0 每按一次，D0 的值加 K5（ADDP 脉冲型加法，3 行格式）。当 D0≥K50 时 Y0 亮。X1 复位 D0 和 Y0。用扩展格式。

**测试指令**：ADDP（3行格式）/ LD>=（比较触点）

---

## 19. 批量复位 — ZRST

> 生成 FX5U PLC 程序：X0 启动后 SET M0~M5（逐个置位）。X1 按下时 ZRST M0 M5 批量复位所有 M 继电器。X2 按下时逐个检查 M0~M5 状态输出到 Y0~Y5。用扩展格式。

**测试指令**：ZRST（2行格式）/ SET / LD

---

## 20. 累计定时器 — OUT ST

> 生成 FX5U PLC 程序：X0 为间歇信号（模拟按钮点动）。用累计定时器 ST0 记录 X0 总共接通时间，累计满 10 秒（K100）后 Y0 亮。X1 复位 ST0 和 Y0。用扩展格式。

**测试指令**：OUT ST（累计定时器）/ RST T

---

## 测试注意事项

1. 每条用例生成后导入 GX Works3 验证
2. 检查是否有"无法读取软元件"、"梯形图配置不正确"等错误
3. 确认注解列全部为空
4. 确认定时器参数为扩展格式（参数独立行，步号为空）
5. 如发现格式或逻辑问题，记录错误行号和内容，反馈给 skill
6. 3 行格式指令（ANS/ADDP/BMOV 等）确认参数行步号为空
7. FROM/TO 4 行格式和 ADPRW 6 行格式确认参数数量正确
