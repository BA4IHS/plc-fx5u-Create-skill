# 三菱 FX5U PLC 程序生成器

根据语言描述的控制需求，自动生成符合 **GX Works3** 导入规范的 PLC 程序 CSV 文件。

## 功能

- 理解工业控制需求（启停、互锁、定时、闪烁、循环、限位、急停等）
- 自动设计软元件分配（X/Y/M/T/C/F/D）
- 生成 UTF-16LE with BOM 编码的 CSV 文件，可直接导入 GX Works3
- 支持扩展格式（定时器/计数器参数独立行，步号为空）
- 同时生成可复现的 Python 脚本和最终 CSV 文件

## 文件结构

```
plc-fx5u-generator/
├── SKILL.md                          # Skill 主文件
├── references/
│   ├── csv-format-spec.md            # CSV 格式详细规范
│   ├── instruction-set.md            # FX5U 指令参考
│   └── program-examples.md           # 典型程序示例
└── scripts/
    └── write_csv.py                  # CSV 写入工具
```

## 支持的控制场景

- 电机启停与自锁保持
- 正反转互锁控制
- 定时循环运行
- 点动与长运行互锁
- 故障报警（闪烁/常亮/熄灭）
- 限位保护与自动循环
- 抢答器/竞赛控制
- 电梯/送料小车等复杂流程

## 快速开始

在 Claude Code 中描述控制需求即可，例如：

> 生成一个FX5U PLC程序：按下启动按钮X0，电机Y0运行5秒后停止3秒，如此循环。急停X1立即停止。

Skill 会自动：
1. 分析控制需求，设计软元件分配
2. 生成 Python 脚本（可复现）和 CSV 文件
3. 输出到桌面 `ProgPou_<程序名>.csv`

## CSV 格式说明

| 项目 | 规范 |
|------|------|
| 编码 | UTF-16LE with BOM |
| 分隔符 | 制表符 (Tab) |
| 列包围 | 双引号 |
| 文件头 | 3 行固定格式 |
| 步号 | 偶数递增，参数行留空 |
| 定时器时基 | 100ms（K值 = 秒数 × 10） |
| 注解列 | **必须为空** |

## 注意事项

- **注解列必须为空**：第 7 列填入文本会导致 GX Works3 导入失败
- 急停逻辑必须复位所有输出和中间继电器
- 正反转/上下行必须互锁（ANI Yx）
- 输出文件默认保存到 `C:/Users/admin/Desktop/`

## 安装

将此目录放入 `~/.claude/skills/` 即可在 Claude Code 中使用。
